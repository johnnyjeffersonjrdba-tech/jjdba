Como gerar o token (uma vez só)
  1. Abra GitHub → novo token (fine-grained).
  2. Nome: admin-blog · Expiração: 1 ano.
  3. Repository access: Only select repositories → jjdba.
  4. Permissions → Repository → Contents: Read and write.
  5. Gere, copie e cole acima. Não compartilhe esse token.
